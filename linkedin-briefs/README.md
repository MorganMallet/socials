# LinkedIn post briefs, Morgan & Mallet

One file per post. Claude Code writes and fact-checks the words. Claude Design makes the visuals. Claude Code then posts the finished files through PostEverywhere.

- `ben/`: Ben Washington's posts (PostEverywhere 5715). Audience: family offices, wealth managers, luxury real estate.
- `laurine/`: Laurine Mallet's posts (PostEverywhere 6334). Audience: household staff candidates.

Only posts marked image or carousel need design work. Text posts are listed so the batch is complete.

## Brand

Use the **Morgan Mallet Design System** in Claude Design (the organisation's default). If it is not available, these are its values:

| Token | Value | Use |
|---|---|---|
| Navy | #001749 | Main background or main text |
| Gold | #C59B40 | Hairline rules, small labels, numbers to pick out |
| Cream | #FCFAF5 | Light backgrounds, text on navy |
| White | #FFFFFF | Text on navy, page surface |
| Grey text | #6D7172 | Source lines on light backgrounds |

Type: FreightBig Pro for headlines (stand-in: Cormorant Garamond), Avenir for body and figures (stand-in: Nunito Sans).

Look: quiet luxury, editorial. Flat navy or cream fields, thin gold rules, generous space. No gradients, no emoji, no icons in place of words, no stock-photo people. The wordmark is "Morgan & Mallet".

Photography is optional. If a post uses a photo background, it must be photoreal, no people, no text baked in, in the house grain style (cream, sand, soft navy, film grain). Higgsfield can make one. Keep the figures readable on top of it.

## House rules (non-negotiable)

1. Every word and number in ON-IMAGE TEXT or SLIDES is final. Copy it exactly. Do not round, reword, shorten, add a tagline, or drop a source line.
2. No em dashes or en dashes anywhere. No emoji.
3. Every figure keeps its source line on the image, in small type.
4. Size: 1080 x 1350 px (4:5 portrait) for every image and every carousel slide.
5. Carousels are exported as ONE PDF (LinkedIn document post), plus a PNG per slide.
6. Never name LinkedIn automation tools on any post.
7. If something will not fit, say so. Do not cut words to make it fit.

## Hand back

For each post: the PNG (and the PDF for carousels), named like the brief, for example `ben/post-01-what-us-household-staff-earn.png`. Put them in a Drive folder or commit them under `linkedin-briefs/out/` in this repo, then tell Claude Code where they are. Claude Code checks them against the brief and schedules them.
